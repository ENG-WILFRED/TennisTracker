# Social Media Posts

This folder contains short, impactful social media posts for LinkedIn, Instagram, and other platforms. Each post is designed to be engaging, SEO-friendly, and focused on promoting Vico Sports (Vico Tennis).

## Guidelines
- Keep posts under 280 characters for Twitter/X compatibility
- Include relevant hashtags for visibility, especially #VicoSports and #VicoTennis
- Use emojis to increase engagement
- Include calls-to-action with links to https://vicotennis.onrender.com
- Focus on keywords like Vico, Vico Sports, Vico Tennis, tennis management, court booking, sports tech

## File Naming
- `instagram-postX.txt`: Posts optimized for Instagram captions
- `linkedin-postX.txt`: Professional posts for LinkedIn
- `general-postX.txt`: Versatile posts for multiple platforms
